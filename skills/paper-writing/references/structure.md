# 论证、段落与信息分配

起草、重组或审校章节逻辑时使用。局部语言修改不必重新设计整篇论文。下面的记录可保留为内部文字条目，只在用户要求解释或实质性结构变化时展示。

### 起草或大幅重组

1. **明确一句话论证**：在 `[对象/问题]` 中，作者用 `[方法]` 得到 `[发现/贡献]`，由 `[证据]` 支持，成立于 `[范围/条件]`。只能填作者材料；写不出时说明缺的科学信息。
2. **建立术语记录**：标准词形、全称与首次定义、已见变体、同名异义、单位与符号。能明确判断的选择说明即可，真正影响领域含义的冲突才询问。后续沿用，作者改名后只在授权范围内同步相关出现并说明未覆盖位置。
3. **按论文类型安排论证**：research 从实际发现与证据出发；methods 从技术核心、可复现性和公平比较出发；hypothesis 从可区分的机制假设及已有支持/反证出发；algorithmic 从任务、程序、协议、公平评估和失败边界出发；review 从文献主题、已知、分歧与未知出发。不存在的实验或因果证据不得补造。
4. **为段落指定职责**：背景、缺口、方法、结果、比较、机制、意义、局限。写下段落主张和对应证据，避免一个段落混入互不相干的任务。
5. **主张—证据映射**：supported、partial/needs evidence、inferred。缺证据时仅标注缺项，或在授权修订中把主张收窄到已支持范围；不要用更多漂亮措辞掩盖缺口。
6. **先决定结果信息的功能与位置**，再写 Results；每个核心问题应在结果中得到回答，不能按实验做过的时间顺序堆积正文。
7. **从证据向外写**：主张靠近支持它的数据和比较；推断紧接直接证据，并保留边界。完成完整段落，而不是交付规划提纲来代替作者要求的正文。
8. **修订三层**：章节逻辑 → 段落主题与证据 → 句法和自然表达。先暴露无法靠文字解决的问题，再润色。

### 已有稿件的诊断与逆向提纲

先判断是论文类型不合、缺口含糊、主张无证据、证据无主张、边界缺失、章节职责错位、术语漂移、主文过长、重复统计或仅有语句问题。采用 `论文类型 → 章节职责 → 证据位置 → 段落必要性 → 主张/证据/边界 → 句子` 的顺序处理。

逆向提纲记录：章节主张、各段主题句、各段证据/解释；核对“段落主题句支持章节主张”和“段内证据支持主题句”两层关系。找不到映射的段落优先移位、合并或标注问题，不靠堆连接词补救。保守润色中不擅自大改结构，给出必要的结构问题说明。

### 针对反馈修订

保持未受影响的段落原样。作者说“这里不是我的意思”时定位具体主张、段落或结果顺序；必要的邻近变化一并说明，不全篇重写。每个新增句先确认新功能，再查找已有同功能句，优先替换、合并或压缩。修改后只复查受影响的术语、事实、主张和衔接；新发现表明问题更广时再扩大相关检查。

## 读者问题与论文类型

读者依次判断：是否与问题相关，有什么新知识，证据是否可信，方法/结论能否复用，意义和边界在哪里。背景、方法与意义的顺序应服务这些问题。

- research：现象/问题 → 实际发现 → 决定性证据 → 解释和边界；先稳定结果，再组织引言，摘要最后收束。
- methods：任务与现有不足 → 方法设计 → 公平比较 → 可复现细节 → 失效范围；先写技术核心和已有评估，再写问题框架。
- hypothesis：明确假说、可区分的替代解释及支持/反证；区分相关证据与能够支持因果/必要性的设计。
- algorithmic：输入输出、程序/模型、评估协议、强基线、资源与泛化条件；“更好”必须说明相同条件下比较什么。
- review：按主题、机制或争议综合实际阅读的文献，区分一致结论、差异来源和真实未知，不套原始研究的实验结构。

这些是论证重心，不能要求用户补齐不存在的实验，也不强制改变既有期刊结构。

## 术语记录

记录标准词形、全称/首次定义、已有变体与决定；额外区分同名异义及同义异名。锁定方法、模型、对象、数据集、指标、单位和符号。样稿只校准文风，不能移入样稿事实。后续沿用已经确认的词形，不为词汇变化创造近义术语。

## 结果按八种功能分配

- 核心发现：推进中心结论，主文提供充分证据。
- 必要支持：读者接受核心发现不可缺少，主文简明呈现。
- 限定：改变方向、大小、范围或可信性时必须在主文可见。
- 稳健性：检验同一结论对设置变化是否稳定；若不改变判断，可在已有补充材料说明。
- 异质性：组别/条件差异本身是中心发现时进主文，否则建议放补充材料。
- 来源与实现细节：服务追踪和复现，归入方法或已有补充材料。
- 替代推断：同一主张的第二条分析路线，除非改变接受程度，否则不重复占主文。
- 边缘/失败条件：改变主张的适用方式时在主文明确，非中心细节才建议后置。

按在本论文的作用分类，不按实验名称分类。消融可成为机制论文的核心发现，边缘条件也可能改变主结论。只建议信息安排，不声称创建了不存在的补充材料。

## 最短充分证据链与删改检查

保留完整证据记录，不要求完整分析过程都占主文。正文应让读者看到中心观察、决定性比较/机制支持、关键不确定性和改变结论的条件。矛盾证据、必要限定和规定报告的信息不能为压缩而隐藏。

删除段落前判断：去掉后是否仍能理解并充分接受中心主张？若只一个句子不可缺少，就保留它并处理其他重复内容。新增文字前，说明它的新功能，寻找同功能旧句，优先替换/合并；不要把正文写成预先答审稿人。

一项主张可在不同位置引出、证明、解释、综合，但不能在标题、段落、题注、讨论和结尾重复完整统计与同一推断。主文负责发现和决定性支持，题注负责对象与读法，已有补充材料负责非中心细节。不能只挑最有利统计量，也不能删除复现或目标规范所必需信息。

## 结构检查

引言每个核心问题应在结果有答案，结果每个中心主张应在引言有动机。讨论重复一个结果时必须增加综合、文献关系或边界功能。若文字主张超过现有证据，标明缺口；授权修订时可收窄主张，不以新修辞补证据。
