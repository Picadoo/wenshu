# Contributor instructions

Default to Chinese when collaborating with the maintainer. Preserve code identifiers and filenames.

- Read `docs/CODEX_MEMORY.md` and inspect Git status before editing.
- Keep the change focused and preserve unrelated edits.
- Never commit private libraries, personal notes, annotations, reading history, credentials, local configuration, databases, or generated mirrors.
- `examples/vault/` is the only shared example library. Retain the example's copyright notice and CC BY attribution.
- Do not import commercial template source or assets into this repository.
- Validate affected modules. Before publishing, check the staged files and run `python scripts/check-public-tree.py`.
- Do not use desktop UI automation without the maintainer's explicit request.
- Update project memory only for durable decisions; never record secrets or temporary logs.
